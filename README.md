# 1X · Dr. Ayesha

Premium luxury ecommerce-style platform combining **cybersecurity courses** and **physiotherapy services** — inspired by Kylie Cosmetics UI/UX.

## Stack

- Next.js 15 · TypeScript · Tailwind CSS 4
- Framer Motion · React Icons
- Client auth gate (login / signup / guest)
- AmiBOT-style floating assistant

## Getting started

```bash
cd onex
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Use **Continue as Guest** or any email/password to enter the storefront.

## Pages

| Route | Description |
|-------|-------------|
| `/` | Homepage — hero slider, featured courses/services, testimonials |
| `/courses` | Course collection |
| `/courses/[slug]` | Course detail |
| `/services` | Therapy services collection |
| `/services/[slug]` | Service detail |
| `/about` | Dr. Ayesha editorial page |
| `/contact` | Contact & booking form |

## Project structure

```
app/              # Routes & layouts
components/       # UI, layout, home, catalog, chatbot, auth
lib/              # Data, images, utils
```
